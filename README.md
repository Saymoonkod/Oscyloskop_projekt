# Oscyloskop_projekt
Celem projektu jest generowanie podstawowej figury geometrycznej (kostki) na ekranie oscyloskopu.

W trakcie realizacji zadania zostały ustalone pewne fakty:
1. Animacja wygląda najlepiej wyświetlając ją na oscyloskopie analogowym.
2. Zalecane jest ustawienie głośności systemowej na około 80% poziomu maksymalnego

Jak włączyć animację?
1. Podłączyć do oscyloskopu przewody BNC i wyjścia połączyć do kabla jack 3,5mm
2. Przewód jack 3,5mm połączyć bezpośrednio z komputerem
3. Włączyć skrypt NowaAnimacja.py
4. Dostosować prędkość obrotu kostki (zmienna
